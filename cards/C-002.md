## Scope

Vertical slice theo flow/law/CLAUDE.md standard sequence mục 2 — chứng minh seam chạy end-to-end TRƯỚC khi tốn công vào UI thật:

1. `app/api/suggest/route.ts` — POST handler đúng flow/05-contract.md:
   - Validate input: `ingredients` là mảng 2–8 phần tử, mỗi phần tử 1–40 ký tự sau trim, không trùng → sai thì 400 `{error}`.
   - Thiếu env `GEMINI_API_KEY` → 502 với error message nêu rõ tên biến (fail loud, không default âm thầm).
   - Gọi Gemini `gemini-2.5-flash` (structured output JSON, `thinkingBudget: 0`, timeout 10 giây) — prompt giới hạn món ăn gia đình Việt Nam theo ADR quyết định 6.
   - Map lỗi: Gemini 429 → 429 `{error}`; lỗi khác/timeout/JSON sai schema (validate từng trường Recipe server-side) → 502 `{error}`.
   - Đúng schema → 200 `{recipes}` (0–3 phần tử).
2. `app/page.tsx` — trang gọi thử MỘT trang, chủ đích xấu: ô nhập nguyên liệu phân tách bằng dấu phẩy + nút "Gợi ý món ăn" + hiển thị JSON thô/lỗi. Ghi chú rõ trong code: đây là placeholder của vertical slice, sẽ bị thay bởi UI mock card theo sequence (law cấm frontend thật trước khi mock được duyệt).
